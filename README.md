# 公司开票信息管理（云端多人共享版 v1.5）

网页部署在 Vercel，正式数据保存在 Supabase Postgres 数据库中。

## v1.5 主要功能

- 管理员可为每位成员设置“查看全部公司”或“只查看指定公司”。
- 指定公司权限可随时增加、取消；保存后成员刷新页面即可生效。
- 选择“查看全部公司”的成员会自动看到以后新增的公司。
- 选择“只查看指定公司”的成员不会自动看到新公司，需管理员再次授权。
- 权限在后端接口执行，不只是隐藏页面内容；成员无法通过接口读取未授权公司。
- 保留 v1.4 的独立账号、停用账号、访问记录、重复保存判断和弹窗顶部错误提示。

## Vercel 环境变量

- `SUPABASE_URL`
- `SUPABASE_SECRET_KEY`
- `ADMIN_PASSWORD`
- `SESSION_SECRET`

`TEAM_PASSWORD` 已不再用于共享成员登录。

## 已有项目升级

1. 在 Supabase SQL Editor 执行 `supabase/migration-v1.5.sql`。
2. 该脚本是累计升级脚本，无论是否已经执行 v1.4 都可以直接运行，并且不会删除现有开票信息。
3. 上传本项目文件到 GitHub 仓库根目录并提交。
4. 等待 Vercel 自动部署为 `Ready / Latest`。
5. 管理员进入“成员管理”，点击成员右侧的“设置查看权限”。
